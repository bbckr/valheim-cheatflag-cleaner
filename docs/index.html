Valheim Cheat Flag Cleaner

Removes the "Achievement progress is permanently disabled for this character due to dev command usage" mark from a Valheim 1.0 character. Your save is processed in this browser only. Nothing is uploaded.

How to use it

  1. Close Valheim. If it's running, the game can overwrite your fix when it saves.
  2. Open your character folder. Paste this into the Windows Explorer address bar:
    %USERPROFILE%\AppData\LocalLow\IronGate\Valheim\characters_local
    Steam Cloud characters are in characters instead of characters_local. Linux / Steam Deck: ~/.config/unity3d/IronGate/Valheim/
  3. Make a backup: copy yourname.fch somewhere safe.
  4. Drop yourname.fch above, then click Clean & download.
  5. Move the downloaded file into the character folder and replace the old one. Keep the exact same file name.
  6. Start Valheim and load your character.
What exactly does this change?

Three things in the .fch file, and nothing else:

  • The character's persistent used cheats flag is set to false.
  • The Cheats counter in the character statistics is set to 0 (optional).
  • The file's SHA-512 checksum is recalculated so Valheim accepts the file.

Skills, inventory, map, appearance and everything else stay as they are. If the file doesn't match the expected layout, the tool refuses to change it instead of guessing.

Steam Cloud keeps putting the old file back

If your character is in the characters folder (Steam Cloud), Steam may restore the old copy. Turn off Steam Cloud for Valheim (Steam → right-click Valheim → Properties → General), replace the file, launch the game once, then turn Steam Cloud back on.

The warning still appears

Valheim has other kinds of cheat marks. "…temporarily disabled… cheated items" means you're carrying a spawned item, so drop it or put it in a chest. "…disabled for this world…" is stored in the world save, not the character. Using most dev commands again (spawn, god, debugmode…) will set the flag again.
